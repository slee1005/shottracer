# 무료 배포 설정

2026-11-04 사용자 요청으로 기존 월 US$2.99 구독 계획을 무료 배포로 변경했다. 앱은 기간 제한·결제·로그인·코드 없이 사용할 수 있다. 기본 워터마크는 유지한다.

- Android Play Billing과 iPhone StoreKit 구매·복원·만료 차단을 제거했다.
- Android 결제/네트워크 권한과 결제 공개키 빌드 요구가 없다.
- `products.json`은 무료 배포 상태를 기록하며 상품 목록은 비어 있다. `ShotTracer.storekit`도 상품이 없는 로컬 설정이다.
- 기존 만료 기록을 읽지 않고 프로젝트·앨범 데이터는 유지한다. 별도 Android 테스터 패키지도 무료이며 연장 코드를 받지 않는다.
- `tools/issue_access_codes.py`·공개키·해당 테스트는 과거 개발 도구로 남기며 앱에 포함하거나 무료 이용 조건으로 사용하지 않는다. 과거 구독 구현은 Git 커밋 `9ece37c`에서 확인할 수 있다.
- 기존 로컬 업로드 서명키는 계속 사용한다. 키·비밀번호·인증정보는 커밋하지 않는다.

서명 파일·배포 절차는 [무료판 Play 배포 안내](PLAY_RELEASE.ko.md)를 참고한다. 실제 스토어 공개·실기기 검증은 별도다. 이미 운영 중인 구독이 있다면 앱 업데이트만으로 스토어 구독이 취소되지는 않으므로 Console에서 별도로 확인한다. 이번 작업에서는 계정·기존 구독을 조회하거나 변경하지 않았다.
