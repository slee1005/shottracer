## 1. 확정된 범위와 구조

- PC·클라우드 없이 휴대전화에서 영상 편집·자동 추적·출력한다. 시작 공은 사용자가 선택한다. 최초 공 위치의 완전 자동 탐색은 기준 범위 밖이다.
- Android는 Kotlin, iPhone은 SwiftUI, 공통 코어는 C++17/C ABI다. Flutter는 검토 대안이며 설치된 의존성이 아니다.
- Android 최소 OS는 Android 14(API 34), 현재 compile/target은 API 36이다. iPhone 요청 최소 OS는 iOS 26.6.2로 프로젝트에 설정되어 있으나 실기기·SDK 호환성 확정은 남아 있다.
- 인물 가림, 자동 클럽·손목 경로, 전용 퍼트 추적을 양 플랫폼에 구현했다.
- 영상·분석은 로컬에서 처리한다. 무료판은 결제 통신·SDK를 사용하지 않는다.
- 현재는 기간 제한 없는 무료 배포다. 72시간 체험·월 US$2.99 구독은 과거 계획이며 폐기했다.
- 기존 기록상 Google Play 계정은 보유했고 계정 유형·검증·프로덕션 접근은 미확정이다. Apple Developer Program은 미가입으로 기록되어 있다. 이번 문서화에서 계정 상태를 재조회하지 않았다.

### 이번 문서화의 재검증

2026-11-04 기존 가상환경에서 `.venv/bin/python -m pytest`를 실행해 **85개 모두 통과(10.07초, 건너뛴 테스트 없음)**했다. `uv run pytest`는 기본 캐시 접근 제한으로 시작하지 못했고, 임시 캐시를 지정한 오프라인 실행도 uv의 macOS 시스템 설정 초기화 오류로 종료하여 직접 실행으로 대체했다. Android/iPhone 빌드·실기기·스토어 검증은 이번에 재실행하지 않았다.

### 이전 구독판 Play 산출물 기록 (코드 1, 현재 배포용 아님)

- 정식 ID `com.ajc.shottracer`, 버전 `0.0.1`, versionCode `1`. 개발판 `.dev`, 테스터판 `.dev.tester`는 데이터를 별도로 유지한다.
- 기존 생성 기록: `release/ShotTracer-0.0.1-play.aab`, 43,612,838바이트. 옆에 체크섬·검증 JSON을 저장한다. 이번 문서화에서 바이너리를 재생성하거나 무결성을 재검사하지 않았다.
- `tools/build_play_bundle.py`가 빌드·검증한다. 서명 설정·키는 제외된 `private/`, 산출물은 제외된 `release/`에 둔다.

## 5. 남은 작업

1. **실기기:** 기종·OS를 기록하고 실제 골프 영상의 추적, 카메라·마이크·회전·VFR·코덱·앨범·열·메모리를 확인한다. 요청 iOS 최소 버전과 실제 도구·기기의 호환성도 확인한다.
2. **무료 판매 설정:** 스토어 가격을 무료로 설정하고 구독 상품을 신규 배포의 요구 사항에서 제외한다. 이미 운영 중인 구독이 있다면 Console에서 별도로 확인한다. 이번 작업은 스토어 계정이나 구독을 변경하지 않는다.
3. **Google Play:** 내부 테스트, 앱 서명, 개인정보·Data safety·콘텐츠 등급·심사 안내와 계정별 테스트·프로덕션 접근 요건을 완료한 뒤 제출한다. 이 문서는 최신 스토어 정책을 재확인한 안내가 아니다.
4. **Apple:** 개발자 가입, 서명·기기 설치, App Store Connect 무료 판매·개인정보·심사 자료·배포 테스트를 준비한다.
5. **안정성:** 백그라운드 분석·출력, OS 종료 후 미완료 작업 복구, 캐시 정리·접근성·주석/팝업 보강을 검토한다. 과거 체험·코드 기록은 무료판에서 사용하지 않는다.
6. **추가 이식:** 데스크톱 프로젝트 가져오기·모바일 워터마크 암호 해제·임의 자유곡선은 별도 범위를 정한다. 모바일 이동 보정과 네이티브 인물 분석이 데스크톱 LK/RANSAC·포즈 결과와 동일하다고 가정하지 않는다.
