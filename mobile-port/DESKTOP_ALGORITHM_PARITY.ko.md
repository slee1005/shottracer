# macOS 추적 알고리듬의 모바일 적용 확인

기준: 2026-11-20. macOS Python과 Android/iPhone의 실제 호출 경로를 대조했다.

비행 수식·피팅·착지·정점 보정은 기존 공유 C++에 이미 이식되어 있었다. 이번에는 초기 프로토타입으로 남아 있던 전처리·카메라·공 검출을 보완하고 두 앱의 분석·좌표 편집·미리보기·내보내기에 연결했다.

## 대조 결과

| 공 자리 이탈 | 한 픽셀 밝기 | 공 주변 패치 상관계수와 후속 프레임 이탈 검사 |

## 앱 연결

Android와 iPhone의 `TrackingSession` 생성자가 `st_use_desktop_tracking`을 호출한다. 라이브 카메라도 같은 생성자를 사용한다. 첫 RGBA 영상은 `st_reference_rgba`로 전달하고, 추적에는 회색조 영상과 원본 초 단위 PTS를 입력한다. 가져온 영상의 디코딩이 끝나면 `st_finish`로 짧은 출발 검사 대기를 처리한다. 다음 이미지가 없는 마지막 프레임을 검출 관측으로 만들어 넣지 않는다.

`st_camera_transform`의 비대각 계수에는 가로·세로 비율이 포함되므로 세로 영상 회전을 처리할 수 있다. 재분석 시 착지 좌표에는 이전 행렬의 정방향과 새 행렬의 역방향을 적용한다. 같은 `EditorRenderer`가 미리보기와 출력에서 사용된다. 기존 C ABI의 프로토타입은 호환·회귀 비교용으로 남지만 앱은 새 경로를 명시적으로 선택한다.

## 유지하는 모바일 차이

- macOS는 OpenCV의 LK/RANSAC을 호출한다. 모바일은 같은 단계의 휴대 가능한 C++ 구현을 사용하며 OpenCV 바이너리 의존성을 추가하지 않는다. 특징점·마스크·픽셀 결과의 완전한 동일성을 뜻하지 않는다.
- 최대 30fps, 최대 변 640px와 원본 PTS를 유지한다. 확인한 시작·착지 시간 차이를 비행 시간 사전값으로 쓰고 라이브는 full-shot 기본 범위를 사용한다. 실제 거리·속도 측정값은 아니다.
- 작은 래스터에서는 지정 공의 반지름도 후보와 큰 움직임의 면적 제한에 반영해 가까운 공을 통째로 제외하지 않는다.
- 인물 분리는 Android MediaPipe와 iPhone Apple Vision을 유지한다. 현재 제거된 클럽·스윙 UI는 복구하지 않는다. 데스크톱 스윙 극좌표 평활화를 모바일 편집기에서 실행한다고 주장하지 않는다.
- 모바일 리본, 거리 표시, 수동 시작·정점·착지 곡선, 퍼트 중간점과 워터마크를 유지한다. 수동 곡선은 macOS Bézier/호 길이 경로와 완전히 같은 구현이 아니다.
- 라이브에는 출발 검증의 짧은 지연이 추가된다. 이전 영상 두 장과 기존 직렬 처리·제한된 큐를 사용한다. 실제 기기의 프레임률·열·메모리는 별도 검증이 필요하다.

## 검증과 근거

2026-11-20 최종 확인: `uv run pytest` **115개 통과**, Android JVM **42개 통과**, Android 디버그 APK·린트와 iPhone device SDK 무서명 빌드 성공. 스토어 업로드나 실기기 설치는 수행하지 않았다.

실제 C ABI를 C++17로 컴파일해 출발·공 자리 유지·잔디 경계·누락 재검색·소실·중복 종료·VFR·패딩 stride를 검사한다. 알려진 이동·회전·확대/축소와 세로 영상의 행렬을 비교하고, 데스크톱 비행식으로 만든 회전 영상에서 실제 관측과 렌더링 끝점의 좌표 일치를 확인한다. 다음 이미지가 없는 마지막 프레임이나 없는 검출은 관측으로 저장하지 않는다. 낮은 밝기/어두운 퍼트도 검사한다. 기존 비행 모델·피팅·착지·정점의 Python 수치 동등성 테스트는 유지한다.

Android의 좌표 왕복·시각 보간·세로 비율·이전 이동량 호환은 JVM 테스트로 검사한다. 앱은 Android 디버그 APK·린트와 iPhone device SDK 무서명 빌드로 검증한다. 실촬영 골프 영상·실기기·스토어 공개 검증은 별도다.

- `core/src/desktop_camera.hpp`: 영상, 코너, 피라미드 LK, RANSAC
- `core/src/desktop_tracking.hpp`: 중심, 지평선, 세 프레임 후보, 출발, 비행/퍼트
- `core/include/shottracer.h`, `core/src/shottracer.cpp`: C ABI와 기존 수식·래스터
- Android `NativeCore.kt`, `CameraTransform.kt`, `EditorScene.kt`, `MainActivity.kt`: 호출·저장·편집·합성
- iPhone `TrackingSession.swift`, `EditorModel.swift`: 호출·저장·편집·합성
- `tests/test_core.py`, Android `CameraTransformTest.kt`: 수치·영상·호환 검사
