## 1. 현재까지 만든 것

ShotTracer는 골프 영상에서 시작 공을 선택한 뒤 공을 추적하고, 비행 모델을 이용해 트레이서와 스윙 경로·정보 팝업을 합성하는 로컬 영상 편집기다.

| 구분 | 구현 내용 | 주요 위치 |
| --- | --- | --- |
| 분석 | 카메라 움직임 보정, 임팩트·공 추적, 원근 비행 모델, 퍼트 추적 | `src/shottracer/camera.py`, `ball.py`, `trajectory.py`, `putt.py` |
| 인물·스윙 | 인물 뒤로 지나가는 궤적, 클럽헤드·손 경로, 수동 스윙 포인트 | `person.py`, `swing.py` |
| 편집 | 최대 4개 샷, 수동 궤적, 착지점·최고점 도달 시간·속도 조절, 실행 취소·다시 실행, 초기화 | `settings.py`, `engine.py`, `web/` |
| 출력 | 원·선 주석, 팝업, 로고, 기본 워터마크, 슬로모션, 일괄 출력 | `render.py`, `popups.py`, `watermark.py` |
| 실행 | CLI, 로컬 FastAPI 웹 편집기, pywebview 독립 실행 앱 | `cli.py`, `server.py`, `desktop.py` |
| 패키징 | macOS Apple silicon·Windows x64 앱, ffmpeg·포즈 모델 포함, Actions 빌드 | `packaging/`, `.github/workflows/build-app.yml` |
| 문서·언어 | 영문·한글 사용법, 설치·CLI 안내, 구조·인수인계 문서 | README 두 파일, `docs/ARCHITECTURE.md`, `AGENTS.md` |

데스크톱은 Python 3.13 + FastAPI + 일반 JavaScript로 구성된다. 영상 처리는 로컬에서 수행하고 서버는 `127.0.0.1`에 바인딩한다. 개발자 버전의 최초 모델 다운로드는 해시를 검증한다.

## 3. 유지해야 할 설계

- 자동 분석 원본 `base_model`은 보존하고, 편집은 `engine.apply_edits`로 `model`에 반영한다. 위치·타이밍 편집으로 전체 재분석을 실행하지 않는다.
- 데스크톱 미리보기와 내보내기는 같은 `render.Renderer`를 사용한다.
- 사용자 좌표는 특정 프레임의 영상 픽셀 기준이다. 분석 픽셀·기준 좌표·출력 픽셀을 혼용하지 않는다.
- 기존 프로젝트는 기본값과 Pydantic 마이그레이션으로 계속 읽을 수 있어야 한다.
- 워터마크는 기본 활성화하고 salted scrypt 암호 검증을 유지한다.
- 웹 UI 문자열은 `web/i18n.js`의 en/ko를 함께 갱신한다.

데이터 모델·좌표계·저장 구조·파이프라인·API는 [ARCHITECTURE.md](ARCHITECTURE.md)를 참고한다.

## 4. 검증과 남은 한계

기존 데스크톱 인수인계에는 **50개 테스트 통과**가 기록되어 있다. 모바일 추가 후 Python·공통 코어·코드 발급기·번들 검사까지 **85개**로 확장되었고, 무료판 배포 회귀 검사를 더한 현재는 **92개 모두 통과**했다. 이번 재실행 결과와 기존 모바일 빌드·에뮬레이터 검증은 [모바일 검증 기록](../mobile-port/WORK_LOG.ko.md#4-검증-기록)에 구분해 기록했다.

- 공 대비가 낮아 추적이 끊기면 이후 궤적은 예측이다. 실제 착지점 지정이 중요하다.
- 퍼트는 합성 영상 중심으로 검증했다. 모션 블러·복잡한 배경에서 클럽헤드 검출도 끊길 수 있다.
- 슬로모션 출력은 무음이다. 데스크톱 분석 범위는 공 지정 프레임 전 1초부터 후 15초까지다.
- 작업 큐는 메모리에 있어 서버 재시작 시 진행 중인 작업을 복구하지 못한다.
- 데스크톱이 직접 참조하는 원본 영상을 옮기거나 삭제하면 해당 프로젝트가 깨질 수 있다.
- 웹 UI·전체 영상 파이프라인 자동 검증과 앱 코드 서명·공증은 남아 있다.
- 2D/3D 지도 트레이서, 드론 영상, 라이브 스트리밍은 미구현이다. 모바일 라이브 촬영·녹화와 스트리밍은 별개다.

다음 주요 작업은 모바일 실기기 검증과 무료 스토어 출시 준비다. [모바일 남은 작업](../mobile-port/WORK_LOG.ko.md#5-남은-작업)에 세부 항목을 정리했다. 데스크톱의 큰 기능 확장은 별도로 범위를 정해 진행한다.
